# Measurements behind "one primitive per need"

Cited by
[concurrency on Effect's own primitives](../../proposed/architecture/2026-11-14-nothing-held-across-a-wait.md).
Run at main `7547ab0`, Effect 4.1.3, Node 22.23.4, after `corepack pnpm
install`. Each script resolves `effect` from `packages/harness`, so it runs
from this directory with `node <name>.mjs`.

"Budget" is `Scheduler.MaxOpsBeforeYield`: the number of steps a fiber runs
before the scheduler takes it off. The default is 2048; a small budget makes
every interleaving reachable in a few hundred runs.

| Script               | What it measures                                                                                                                                                 | Result                                                                                                                                                                                                                                                                   |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `sqlTransaction.mjs` | A competing fiber counts how often it runs inside one `sql.withTransaction` of N inserts, with and without `Scheduler.PreventSchedulerYield`                     | intrusions 0 / 3 / 41 at 90 / 400 / 5000 statements; 0 at every size with the yield off                                                                                                                                                                                  |
| `order.mjs`          | Entry order against call order for the hand-written lane (`chain.mjs`), `Semaphore`, `PartitionedSemaphore` and `TxSemaphore`, budgets 2 to 79; barging          | measured from the calling step, the chain and `Semaphore(1)` reorder the same (39 of 225 each); `TxSemaphore` barges (the holder re-enters ahead of three waiters); `PartitionedSemaphore` with one permit admits one holder across all keys and serves keys round-robin |
| `order2.mjs`         | The same four once each fiber is confirmed queued                                                                                                                | 0 of 225 out of order for all four                                                                                                                                                                                                                                       |
| `tx1.mjs`            | `Effect.tx` and `Effect.txRetry`: what wakes a waiter, what an interrupted or failed body commits                                                                | a waiter wakes on a write to a ref it read, same value included, not on another ref; an interrupted or failed body commits nothing                                                                                                                                       |
| `tx2.mjs`            | A two-ref invariant under `Effect.tx`, budgets 2 to 79; cost per operation. Its last counter orders registrations by a step after the commit and is not a result | 0 broken invariants in 3120 reads; `TxRef.update` about 2.3 to 2.5 µs against `Ref.update` 0.10 to 0.16 µs and `SynchronizedRef.update` 0.4 to 0.7 µs                                                                                                                    |
| `tx3.mjs`            | "Register unless closed" under `Effect.tx`, budgets 2 to 79; whether a conflicting commit re-runs the body; commit order against start order                     | 0 registrations after a close in 780 runs; 3713 bodies re-ran on a conflict; 320 of 1950 six-fiber runs commit out of start order                                                                                                                                        |
| `keyed.mjs`          | `RcMap`, `ScopedCache`, `Cache`, `Effect.cached*`, `Resource` as keyed or shared lifetimes: idle time, a failure's lifetime, a reopen during a close             | no shipped primitive makes a reopen wait for the close; `Effect.cached` keeps a failure; five callers of a cached effect share one run; four concurrent `Resource.refresh` calls ran four acquires                                                                       |
| `fibers.mjs`         | `FiberMap` / `FiberSet` / `FiberHandle`: replacement, `onlyIfMissing`, bounding a close; `Semaphore.withPermitsIfAvailable`                                      | a timeout around `Scope.close` does not bound it (152 ms under 30 ms); `FiberSet.clear` then `awaitEmpty` under a timeout returns at the timeout; no double holder in 200 try-and-refuse runs                                                                            |
| `last.mjs`           | Whether a region with the scheduler's yield off can be interleaved; an `RcMap` of semaphores against the chain                                                   | not interleaved at budget 2 unless the region itself yields or sleeps; the keyed `RcMap` reorders at 11 of 2101 offsets at the default budget, the chain and a bare `Semaphore` at 2; about 3.2 µs a call against 0.7 µs                                                 |
| `terminal.mjs`       | `node terminal.mjs effect < /dev/null` and `node terminal.mjs readline < /dev/null`                                                                              | `Terminal.readLine` fails `QuitError` at once; `readline/promises` `question()` has not settled after 1.5 s                                                                                                                                                              |

`load.mjs` resolves `effect`; `chain.mjs` is a copy of
`packages/harness/src/utils/core/perKeyQueue.ts` as it stood at `7547ab0`.
