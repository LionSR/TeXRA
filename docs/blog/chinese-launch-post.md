TeXRA：给学术写作做的 AI 工具

---

现在写论文挺割裂的。

手头有一堆大模型可以用，Claude、GPT、DeepSeek、Gemini，各有各的好。但真到写论文的时候，你会发现这些工具都不太顺手。想润色一段英文用 Claude，想验算公式用 DeepSeek R1，想处理长文档又得换 Gemini——开着好几个标签页，同一段文字来回复制粘贴，效率反而不如从前。

通用大模型不懂学术写作的规矩。它不明白 LaTeX 里 label 和 ref 要对应，BibTeX 格式有讲究，数学符号前后要统一。你让它帮忙改一段文字，它改完了，你不知道它动了哪里。是润色了，还是偷偷把你的意思改了？得自己一行行对着看。

更要命的是它不会真的算。你贴一段推导让它检查，它说"没问题"，其实它根本没验算，只是看着像对的。你让它找几篇参考文献，它可能直接编几个论文名字糊弄你。这些毛病对写代码影响不大，写论文就没法忍了。

---

做 TeXRA 就是想把这些问题解决掉。

首先是把模型统一起来。Claude、GPT、Gemini、DeepSeek、Moonshot、通义千问都接进来了，在一个地方根据任务切换。校对挑便宜快的，润色挑写作好的，推导挑推理强的。API key 自己配，数据直接走服务商，我们不碰。国内直接用 DeepSeek 就行，便宜，不用折腾网络，V3 和 R1 质量都在线。

然后是针对学术写作做专门的工具。

分两类。一类是 Workflow Agent，丢进去一篇文档，自动跑完输出结果。校对的只管找错改错，不动你的风格；润色的分几轮，先想清楚要改什么，改完再检查有没有改出新问题；画图的你描述一下想要什么，它生成 TikZ 代码能直接编译。还有把论文转 slides、转海报的，组会汇报省得从头做 PPT。手写公式拍照转 LaTeX、录音转文字稿这些也有。

另一类是 Tool-Use Agent，可以跟你来回对话，还能调外部工具。Research Agent 接了 Wolfram，推公式、解方程是真的在算，不是瞎猜。Chat Agent 能帮你看草稿提意见，说哪里逻辑跳了、哪里没讲清楚，还能直接搜 arXiv 和 Crossref 找文献，找到的都是真的，有 DOI 能查。Search Agent 专门做文献检索，arXiv、Crossref、网页都能搜。

---

有几个设计原则。

改动要透明。每次 AI 改完你的文档，能看到精确的 diff，删了什么加了什么一目了然。我们接了 latexdiff，数学公式改了哪个符号都能看出来。而且改动要你确认才生效，不会背着你动东西。

过程要可追溯。每次跑完会存下来用了什么模型、花了多少 token、输入输出是什么，随时能翻回去看。

数据要安全。VS Code 插件，跑在本地，论文只发到你自己选的 API 服务商，我们这边不存任何东西。

用 Overleaf 的话，可以用 Git 把项目 clone 下来，本地处理完再 push 回去，有专门的命令。
