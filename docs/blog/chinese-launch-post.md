TeXRA：一个学术写作的 AI 平台

---

去年冬天写论文，一个引理卡了很久。试着把推导贴给 ChatGPT，让它帮忙看看。回答格式漂亮，思路清晰，花了两小时才发现中间一步是错的，而且它把我定义好的符号换成了别的写法，notation 前后不一致。那天晚上就在想，学术写作为什么就没有一个能用的 AI 工具。

ChatGPT 不是为学术场景设计的。它不理解 LaTeX 结构，不知道 label 和 ref 的对应，生成的 BibTeX 格式经常不对，引用的论文有时候干脆是编的。你把一段文字贴给它改，它返回一个"优化版本"，你不知道它改了什么——是润色了表达，还是把核心观点改掉了。只能一行行对比，或者盲目信任。

跟做研究的朋友聊，痛点一致。不是 AI 不聪明，是通用工具对学术写作太粗糙。写论文最难的不是打字，是想清楚。你有个模糊的想法，想推公式，想理清证明思路，需要一个能讨论的对象。通用 AI 做不到，它只会说"方向很有趣"，给不了实质反馈。让它检查推导，它一本正经说"证明正确"，实际根本没验证。让它找文献，它编几个论文标题配上虚构作者。这些问题对需要严谨性的学术工作不能接受。

---

所以做了 TeXRA，专门为学术 LaTeX 写作设计的 AI 平台。说"平台"是认真的——核心问题不是"让 AI 帮你写论文"，是"让你用最合适的工具完成学术工作每个环节"。

现在大模型太多。Claude 写作好，GPT 通用性强，DeepSeek 便宜且推理出色，Moonshot 上下文长，还有 o3、R1 这类推理模型。每个都有优势，但你不可能开五个标签页来回切换。TeXRA 统一接入，同一界面根据任务选模型。支持五十多个模型、十多个服务商，国内国外都有。用自己的 API key，数据直接发到服务商，不经过我们，不收订阅费，用多少付多少。国内用户推荐 DeepSeek，便宜，不用翻墙，R1 推理能力强。

光有模型接入不够。通用聊天界面对学术写作太原始，需要的不是什么都能聊的助手，是针对学术任务优化的专业工具。设计了两套系统：Workflow Agent 处理可自动化的批量任务，Tool-Use Agent 处理需要交互协作、调用外部工具的复杂任务。

---

Workflow Agent 是自动化流水线。文档扔进去，跑完流程，输出结果。

校对 Agent 找拼写语法错误、LaTeX 格式问题、交叉引用不一致、符号不规范，自动修复。设计原则是最小干预，只修错误不改风格。润色 Agent 提升语言质量，分多轮：先分析制定计划，再执行修改，最后反思检查有没有引入新问题。绘图 Agent 生成或优化 TikZ 代码，描述想要什么图，生成可直接编译的代码。

两个转换 Agent：Paper2Slide 把论文转成 Beamer 演示，提取核心贡献生成十到十五页 slides；Paper2Poster 转成学术海报。组会汇报用得多，不用从头做 PPT。

两个输入 Agent：OCR 把手写公式照片转 LaTeX，会先分析文档已有符号约定，确保 notation 一致；Transcribe 把录音转文字，识别说话人，口述公式转 LaTeX 格式，适合整理会议讨论。

---

Tool-Use Agent 是交互式协作系统。可以调用外部工具，实时运行，来回对话完成复杂任务。

Research Agent 是核心。调用 Wolfram Language 做符号计算，推公式、解方程、数值验证。把推导贴给它，说想证明什么、卡在哪，它用 Wolfram 引擎实际计算，不是猜。能用数值代入检查，确保数学上站得住脚。推完直接生成 LaTeX 格式。还能读取编辑文件，提取图表和参考文献，分析文档结构。

Chat Agent 讨论想法。把草稿贴给它提意见，它说哪里逻辑跳跃太大，哪里论证不够充分，哪里表述有歧义。不会只说"写得不错"，给具体可操作的建议。能搜 arXiv 和 Crossref 找文献，每条引用有真实 DOI、可验证作者、正确 BibTeX。对文件任何修改需要确认才应用。

Search Agent 做文献检索，搜 arXiv 预印本、Crossref 正式发表论文、一般网页，抓取内容做摘要。

---

透明和可控。每次修改都能看精确差异对比，内置 latexdiff，删除红色，新增蓝色，数学公式修改细化到符号级别。保存完整会话历史，每次运行用什么模型、花多少 token、输入输出是什么，都可回溯。能回放历史运行看 AI 怎么推理。

数据隐私：VS Code 插件，本地运行，论文数据只发到你配置的 API 服务商，我们不收集任何东西。

技术要求：TeX Live 或 MiKTeX。API key 支持 Anthropic、OpenAI、Google、DeepSeek、Moonshot、Qwen、OpenRouter。国内用 DeepSeek，价格是 GPT-4 十分之一，R1 推理能力强，检查证明推导合适。插件免费开源。
