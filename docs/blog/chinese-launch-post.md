TeXRA：一个学术写作的 AI 平台

写给每一个在论文和 DDL 中挣扎的人。

---

去年冬天我在写一篇论文，有个引理的证明卡了很久。那天晚上我试着把推导过程贴给 ChatGPT，让它帮我看看哪里有问题。它给了我一个看起来很完整的回答，思路清晰，格式漂亮。问题是我花了两个小时才发现它中间有一步是错的，而且它还顺手把我前面定义好的符号换成了别的写法，导致整个 notation 前后不一致。那天晚上我就在想，为什么学术写作就不能有一个真正好用的 AI 工具？ChatGPT 当然是个很厉害的东西，但它不是为学术场景设计的。它不理解 LaTeX 的结构，不知道 label 和 ref 的对应关系，生成的 BibTeX 经常格式不对，引用的论文有时候干脆是编的。更让人焦虑的是，你把一大段文字贴给它让它帮你改，它返回一个"优化后的版本"，你根本不知道它到底改了什么。是润色了表达，还是偷偷把你的核心观点改掉了？你只能一行一行对比，或者选择盲目信任。

后来我跟很多做研究的朋友聊，发现大家的痛点惊人地一致。不是 AI 不够聪明，而是通用的 AI 工具对学术写作来说太粗糙了。写论文最难的部分不是打字，是想清楚。你有一个模糊的想法，想推一个公式，想理清一个证明的思路，你需要一个能真正和你讨论的对象。但通用的聊天 AI 做不到这个，它只会泛泛地说"这个方向很有趣"，给不了实质性的反馈。你让它帮你检查推导，它可能会一本正经地告诉你"证明是正确的"，但实际上它根本没有真正验证过。你让它帮你找相关文献，它可能会编造几个听起来很像的论文标题，配上虚构的作者和年份。这些问题不是 AI 本身的错，但对于需要严谨性的学术工作来说，这是不能接受的。

---

所以我们做了 TeXRA，一个专门为学术 LaTeX 写作设计的 AI 平台。我说"平台"是认真的，因为我们想解决的核心问题不只是"让 AI 帮你写论文"，而是"让你能用最合适的 AI 工具来完成学术工作的每一个环节"。现在市面上的大模型太多了，Claude 写作好，GPT 通用性强，DeepSeek 便宜且推理能力出色，Moonshot 上下文长，还有各种专门的推理模型比如 o3 和 DeepSeek R1。每个模型都有自己的优势，但你不可能为了写一篇论文同时开五个浏览器标签页，在不同的聊天窗口之间来回切换。TeXRA 把这些模型统一接入了，你可以在同一个界面里根据不同的任务选择不同的模型。我们支持五十多个模型、十多个服务商，国内国外都有。你用自己的 API key，数据直接发到模型服务商，不经过我们，不收订阅费，用多少付多少。对于国内用户，我个人推荐 DeepSeek，价格非常便宜，不需要翻墙，而且它的推理能力在开源模型里是顶尖的，写学术论文完全够用。

但光有模型接入是不够的。通用的聊天界面对学术写作来说太原始了，你需要的不是一个什么都能聊两句的助手，而是一组专门针对学术任务优化过的专业工具。所以我们设计了两套系统：一套是 Workflow Agent，用来处理那些可以自动化批量完成的任务；另一套是 Tool-Use Agent，用来处理需要交互式协作、需要调用外部工具的复杂任务。两套系统配合使用，基本上覆盖了学术写作的全流程。

---

先说 Workflow Agent，这是处理完整文档的自动化流水线。你把文档扔进去，它自己跑完整个流程，输出结果。校对 Agent 会帮你找出文章里的拼写语法错误、LaTeX 格式问题、交叉引用的不一致、数学符号的不规范，然后自动修复。它的设计原则是最小干预，只修错误不改风格，不会把你的文章改得面目全非。润色 Agent 用来提升语言质量，但它不是一次性给你一个答案，而是分多轮工作：先分析问题制定修改计划，再按计划执行修改，最后反思检查有没有引入新的问题。这种设计确保修改是经过深思熟虑的。绘图 Agent 可以帮你生成或优化 TikZ 代码，你描述你想要什么样的图，它生成可以直接编译的代码。还有两个特别实用的转换 Agent：Paper2Slide 可以把你的论文自动转成 Beamer 演示文稿，提取核心贡献生成十到十五页的 slides；Paper2Poster 可以转成学术海报，适合会议展示。这两个功能我们组会汇报的时候用得特别多，不用再从头做 PPT 了。

另外还有两个输入类的 Agent：OCR Agent 可以把手写的数学公式照片转成 LaTeX 代码，它会先分析你文档里已有的符号约定，确保转换出来的公式和你的 notation 一致；Transcribe Agent 可以把录音转成文字稿，自动识别不同的说话人，口述的公式会转成 LaTeX 格式，适合整理会议讨论或者讲座笔记。

---

再说 Tool-Use Agent，这是交互式的协作系统。和 Workflow Agent 不同，Tool-Use Agent 可以调用各种外部工具，在编辑器里实时运行，你可以和它来回对话，一步步完成复杂的任务。Research Agent 是我们花了最多心思做的，因为这是学术工作最核心的部分。它可以调用 Wolfram Language 进行符号计算，帮你推公式、解方程、做数值验证。你把你目前的推导过程贴给它，告诉它你想证明什么、卡在哪一步，它会用 Wolfram 引擎实际计算，不是猜测。它还能用数值代入检查，确保推导在数学上是站得住脚的。推出来之后可以直接生成 LaTeX 格式的表达式。除了计算，Research Agent 还能读取和编辑你的文件，提取论文里的图表和参考文献，帮你分析文档结构。

Chat Agent 用来和你讨论想法，这是我个人用得最多的功能。你可以把一个 section 的草稿贴给它，让它给你提意见，它会告诉你哪里逻辑跳跃太大读者可能跟不上，哪里的论证不够充分需要补充，哪里的表述有歧义可能被误解。它不会只说"写得不错"，它会给你具体的、可操作的建议。它还能直接搜索 arXiv 和 Crossref，帮你找相关文献，每一条引用都有真实的 DOI，可验证的作者信息，正确的 BibTeX 格式。更重要的是，它对文件的任何修改都需要你确认才会应用，不会偷偷改你的东西。Search Agent 专门用来做文献检索，可以搜 arXiv 预印本、搜 Crossref 正式发表的论文、搜一般的网页，还能抓取网页内容做摘要。做文献综述的时候特别有用。

---

还有一点我觉得很重要，就是透明和可控。每次 AI 修改你的文章，你都能看到精确的差异对比，我们内置了 latexdiff，删除的内容红色标注，新增的蓝色标注，数学公式的修改可以细化到单个符号级别。我们还保存完整的会话历史，每次运行用了什么模型、花了多少 token、输入输出是什么，全都可以回溯。你可以回放任何一次历史运行，看看当时 AI 是怎么一步步推理的。这对学术工作特别重要，因为你需要知道 AI 做了什么、为什么这么做、结果对不对，不能稀里糊涂地用。数据隐私方面，TeXRA 是一个 VS Code 插件，完全本地运行，你的论文数据只发送到你自己配置的 API 服务商，我们不收集任何东西，不存任何日志。

技术上说几点。需要装 TeX Live 或者 MiKTeX 用来编译 LaTeX 和运行 latexdiff，这个做学术的应该都有。API key 支持 Anthropic、OpenAI、Google、DeepSeek、Moonshot、Qwen、OpenRouter 等等。如果你在国内，强烈建议试试 DeepSeek 的 API，注册简单，价格大概是 GPT-4 的十分之一，而且 DeepSeek R1 的推理能力非常强，用来检查证明和推导特别合适。插件本身完全免费开源。
