TeXRA：一个学术写作的 AI 平台

写给每一个在论文和 DDL 中挣扎的人。

---

去年冬天，我在赶一篇论文的修改稿。

凌晨两点，reviewer 的三十多条 comments 还没处理完。DDL 还剩五天。我打开 ChatGPT，把一段证明贴进去，让它帮我改改表述。

它给了我一个看起来很漂亮的回答。

问题是，公式是错的。符号前后不一致。更要命的是，它把我论文里定义好的 notation 给换掉了。我花了两个小时才发现这个 bug。

那天晚上我就在想，为什么学术写作就不能有一个真正好用的 AI 工具？

---

聊聊我观察到的问题。

第一个问题是，通用 AI 不懂 LaTeX。

ChatGPT 是个好东西，但它不是 LaTeX 专家。它不知道 label 和 ref 的对应关系，搞不清 equation 和 align 环境的区别。BibTeX 更别提了，它生成的引用格式经常是错的，DOI 是编的，作者顺序也有问题。

第二个问题是，改完你不知道它改了啥。

这是最让人焦虑的。你给它一段五千字的 section，它返回一个"优化后的版本"。看起来差不多，但哪里不一样？它删了什么？加了什么？你只能一行一行对比。或者直接信任它，然后在提交之后发现它把你的核心贡献偷偷改掉了。

第三个问题是，它会编造文献。

"帮我找几篇相关论文。"然后 AI 给你编了五个不存在的论文标题，配上虚构的作者和年份。这不完全是 AI 的错，但对学术写作来说，这是不能接受的。

第四个问题是，你没法和它讨论你的想法。

写论文最难的不是打字，是想清楚。你有一个模糊的 idea，想推一个公式，想理清一个证明的思路。你需要一个能和你讨论的对象，能帮你检查推导有没有问题，能在你的草稿上给出具体的意见。

通用的聊天 AI 做不到这个。它只能泛泛地说"这个方向很有趣"，给不了实质性的反馈。

---

所以我们做了 TeXRA。

它不是又一个套壳 ChatGPT 的产品。它是一个专门为学术 LaTeX 写作设计的 AI 平台。

我说"平台"是认真的。

现在市面上的大模型太多了。Claude、GPT、Gemini、DeepSeek、Moonshot、Qwen... 每个都有自己的优势。Claude 写作好，GPT 通用性强，DeepSeek 便宜，Moonshot 上下文长。

但你不可能为了写论文，同时开五个 tab，在不同的聊天窗口之间来回切换。

TeXRA 把这些模型统一接入了。你可以在一个界面里，根据不同任务选择不同的模型。校对用便宜快速的，深度润色用推理能力强的，处理长文档用上下文长的。一切都在 VS Code 里完成，和你的 LaTeX 工作流无缝衔接。

我们支持五十多个模型，十多个服务商。国内国外都有。你用自己的 API key，我们不过手你的数据，不收订阅费。用多少付多少。

---

但光有模型接入是不够的。

通用的 AI 聊天对学术写作来说太粗糙了。你需要的不是一个什么都能聊的助手，而是一组专门针对学术任务优化过的工具。

所以我们设计了一套 Agent 系统。

校对 Agent 只做一件事：找出你文章里的错误并修复。拼写、语法、LaTeX 语法、label 和 ref 的一致性、数学符号的规范性。它的设计原则是最小干预，只修错误，不改风格。你的声音完全保留。

润色 Agent 用来提升语言质量。它不是一次性给你答案，而是分三轮工作：先分析问题制定计划，再按计划修改，最后反思检查有没有引入新问题。这种设计确保修改是经过深思熟虑的，不是随便改改。

研究 Agent 是我们花了很多心思做的。它可以帮你推公式。你把你的推导过程贴给它，告诉它你卡在哪一步，它会帮你检查前面的步骤有没有问题，尝试不同的方法继续往下推。它还能帮你验证结果，用数值带入检查，确保推导是对的。

聊天 Agent 用来和你讨论想法。你可以把草稿贴给它，让它给你提意见。哪里逻辑不清楚，哪里论证不够充分，哪里需要补充实验或引用。它不会只说"写得不错"，它会给你具体的、可操作的建议。你也可以和它讨论研究思路，帮你理清一个 idea 到底 work 不 work。

绘图 Agent 帮你生成 TikZ 代码。你描述你想要什么图，它给你生成可以直接编译的代码。节点对齐、连接线清晰、标签规范。不用再花三小时调坐标了。

检索 Agent 直接对接 arXiv 和 Crossref 的 API。当你说"帮我找相关论文"的时候，它是真的去搜学术数据库，不是从训练数据里编造。每一条引用都有真实的 DOI，可验证的作者信息，正确的 BibTeX 格式。

还有转换 Agent，可以把你的论文转成 slides 或者 poster。自动提取核心贡献，生成合适的布局。录音转写也支持，开会录音可以直接转成带 LaTeX 公式的笔记。

---

还有一点我觉得很重要：透明和可控。

每次 AI 修改你的文章，你都能看到精确的差异对比。我们内置了 latexdiff，删除的内容红色标注，新增的蓝色标注，数学公式的修改可以细化到单个符号。

更重要的是，每次修改都需要你明确批准。AI 不会偷偷改你的论文。

我们还保存完整的会话历史。每次运行用了什么模型，花了多少 token，输入输出是什么，全都可以回溯。你可以回放任何一次历史运行，看看当时 AI 是怎么推理的。

这对学术工作很重要。你需要知道 AI 做了什么，为什么这么做，结果对不对。

---

说说实际怎么用。

你在写一篇新论文，有个引理的证明卡住了。打开研究 Agent，把你目前的推导贴进去，告诉它你想证明什么、卡在哪里。它会分析你的思路，指出可能的问题，尝试不同的方法帮你继续。推出来之后，它还能帮你把证明写成正式的 LaTeX 格式。

你写完了一个 section 的初稿，不确定写得怎么样。打开聊天 Agent，让它看看你的草稿。它会告诉你哪里逻辑跳跃太大，哪里需要更多解释，哪里的 related work 讨论不够。你可以直接和它讨论怎么改，它给你建议，你决定采纳哪些。

你收到了 reviewer 的意见，需要大改。用检索 Agent 研究 reviewer 提到的那些相关工作，用聊天 Agent 讨论怎么回应每一条 comment，用润色 Agent 提升改完之后的语言质量，用校对 Agent 做最后检查。每次修改都看 diff，确保没有问题。

组会要做 presentation。用转换 Agent 把你的论文自动转成 slides，提取核心贡献，生成要点。你只需要在这个基础上调整，不用从头做起。

这些功能我们自己用了大半年，确实能省很多时间。更重要的是，它让你能专注在真正重要的事情上：想问题、做研究。那些繁琐的格式、排版、润色工作，让 AI 来处理。

---

技术上简单说几点。

TeXRA 是一个 VS Code 插件，本地运行。你的论文数据只发送到你配置的 API 服务商，我们不收集任何东西。

需要装 TeX Live 或者 MiKTeX，用来编译 LaTeX 和运行 latexdiff。这个做学术的应该都有。

API key 自己配置，支持 Anthropic、OpenAI、Google、DeepSeek、Moonshot、Qwen、OpenRouter 等等。国内用户用 DeepSeek 或者 Qwen 很方便，便宜而且不用翻墙。

插件本身免费开源。
