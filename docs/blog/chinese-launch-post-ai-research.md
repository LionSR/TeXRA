TeXRA：科学发现流程中的写作工具

---

科学研究正在被 AI 重塑。AlphaFold 预测蛋白质结构，FunSearch 发现新的数学构造，AI Scientist 尝试端到端的论文生成。这些进展指向一个方向：科学发现的各个环节都可能被加速或自动化。

但目前的工具链还不完整。

假设生成、实验设计、数据分析这些环节已经有了不少 AI 辅助工具。然而，将发现转化为可交流的知识——也就是论文写作——仍然依赖通用的聊天工具。这造成了几个问题。

通用大模型不理解科学写作的结构。它们不知道 LaTeX 的交叉引用机制，生成的 BibTeX 条目经常有格式错误，对数学符号的一致性缺乏把控。更重要的是，它们无法验证推导的正确性。当你请求检查一个证明时，它可能返回"正确"，但这只是基于文本模式的判断，不是数学验证。

对于追求科学严谨性的工作，这种不确定性是不可接受的。

---

TeXRA 是一个运行在 VS Code 中的工具平台，试图在科学写作环节提供更可靠的 AI 辅助。

核心设计理念是将大模型的语言能力与可验证的工具结合。TeXRA 整合了主流 AI 服务（Claude、GPT、Gemini、DeepSeek、通义千问等），但不止于此——它通过 Tool-Use Agent 机制，让模型能够调用外部工具来完成需要精确性的任务。

Research Agent 集成了 Wolfram Language 计算引擎。当需要验证数学推导时，它执行的是真正的符号运算，不是模式匹配。对于复杂度分析、收敛性证明、数值验证，这种方式比纯语言模型更可靠。

Search Agent 直接查询 arXiv 和 Crossref 数据库。返回的每一条引用都有真实的 DOI，可以追溯到原始论文。这避免了语言模型编造文献的问题，也方便构建准确的知识关联。

Chat Agent 可以审阅草稿并提供结构化的修改建议。它理解 LaTeX 语法，能够保持交叉引用的一致性，对公式的修改会精确到符号级别。

---

对于从事 AI for Science 研究的团队，有几个场景可能相关。

理论分析的验证。当你用语言模型辅助推导后，可以通过 Research Agent 用 Wolfram 进行数值或符号验证，确保结论的正确性。

文献网络的构建。Search Agent 返回的是结构化的引用数据，包含 DOI、作者、发表年份，可以进一步用于构建知识图谱或分析研究趋势。

从实验到论文的转化。Chat Agent 可以帮助将实验记录整理成论文格式，保持方法描述的准确性，同时提升语言的清晰度。

版本控制与协作。每次 AI 修改都生成 latexdiff 差异报告，所有运行都有完整的追溯记录。这对于需要复现和审计的科学工作流是必要的。

---

设计上的几个原则。

可验证性优先。能用工具验证的就不依赖模型的"判断"。数学用计算引擎，引用用数据库查询。

修改透明。所有改动都有精确的 diff，用户确认后才生效。

过程可追溯。每次运行记录完整的输入输出，可以回溯推理过程。

数据安全。本地运行，论文只发送到用户配置的 API 服务商。

---

TeXRA 不是端到端的论文生成系统，也不试图替代研究者的思考。它的定位是科学发现流程中的一个环节：将已有的发现准确、高效地转化为可交流的论文形式，同时保持科学写作所需要的严谨性。

项目开源，需要本地 TeX Live 或 MiKTeX 环境。问题反馈请访问 GitHub。
