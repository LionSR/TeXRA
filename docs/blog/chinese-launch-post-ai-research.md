TeXRA：面向 AI 研究者的论文写作工具

---

做 AI 研究，写论文的时间往往不比做实验少。

模型训练完成后，需要整理实验结果、撰写方法描述、推导理论分析、补充相关工作。这些环节都可以借助大模型提高效率，但实际操作中会遇到一些问题。

第一个问题是工具分散。不同的大模型各有所长：Claude 的文字润色效果好，GPT 和 DeepSeek 的推理能力强，Gemini 能处理长上下文。写一篇论文可能需要在多个平台之间切换，每次都要重新粘贴上下文，效率并不高。

第二个问题是格式理解。通用大模型对 LaTeX 的支持有限。它们不理解 \label 和 \ref 的对应关系，经常生成格式错误的 BibTeX 条目，对数学环境的处理也不够稳定。当你请求修改一段文字时，它们返回的结果需要手动检查每一处改动，确认没有引入新的问题。

第三个问题是数学验证。AI 研究的论文经常包含理论分析，需要验证推导的正确性。语言模型可以生成看起来合理的证明，但无法保证数学上的严谨性。同样，当你请求查找参考文献时，它可能会给出不存在的论文信息，这在学术写作中是不可接受的。

---

TeXRA 是一个运行在 VS Code 中的工具平台，试图解决这些问题。

在模型层面，TeXRA 整合了主流的 AI 服务：Claude、GPT 系列、Gemini、DeepSeek、Moonshot、通义千问，以及 OpenRouter 上的开源模型。用户可以根据任务特点选择合适的模型，在同一界面中完成不同类型的工作。API 密钥由用户自行配置，数据直接发送到服务商，不经过中间服务器。

在功能层面，TeXRA 针对学术写作设计了两类工具。

第一类是 Workflow Agent，用于批量处理文档。校对 Agent 检查拼写、语法、LaTeX 语法、交叉引用一致性，只修复明确的错误，不改变写作风格。润色 Agent 采用多轮机制：先分析文本制定方案，执行修改，最后检查是否引入新问题。还有生成 TikZ 图表的绘图 Agent，以及将论文转换为 Beamer 演示文稿的转换 Agent。

第二类是 Tool-Use Agent，支持交互式对话并能调用外部工具。Research Agent 集成了 Wolfram Language，可以执行符号运算、求解方程、进行数值验证，适合检查理论推导。Chat Agent 可以审阅草稿、提供修改建议，也可以搜索 arXiv 和 Crossref 查找文献，返回的引用包含可验证的 DOI 和完整的 BibTeX 信息。Search Agent 专门用于文献检索，支持学术数据库和网页搜索，方便补充 Related Work。

---

对于 AI 研究者，有几个功能可能比较实用。

实验结果整理。Chat Agent 可以帮助分析实验数据，提炼关键发现，组织成论文中的表格和图表描述。你可以把原始结果贴给它，让它帮你找出值得强调的对比和趋势。

理论推导验证。Research Agent 通过 Wolfram Language 进行实际计算，不是模式匹配。对于复杂度分析、收敛性证明等，可以用数值验证来检查推导是否正确。

文献检索。Search Agent 直接查询 arXiv 和 Crossref，返回真实存在的论文。对于快速发展的领域，可以方便地找到最新的相关工作，避免遗漏重要引用。

版本对比。每次 AI 修改都会生成 latexdiff 差异报告，可以精确看到每一处改动。这对于多人协作或者投稿前的最终检查很有帮助。

---

设计上坚持几个原则。

修改透明。所有改动都有精确的 diff，数学公式的修改可以细化到单个符号。改动需要用户确认才会生效。

过程可追溯。每次运行记录模型、token 消耗、输入输出，可以回溯查看 AI 的推理过程。

数据安全。本地插件运行，论文只发送到用户配置的 API 服务商，不收集用户数据。

Overleaf 用户可以通过 Git 克隆项目到本地处理，完成后推送回去。

---

TeXRA 需要本地 TeX Live 或 MiKTeX 环境。对于国内用户，DeepSeek 是一个性价比较高的选择，V3.2 模型质量不错，无需特殊网络配置。
