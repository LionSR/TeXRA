LaTeX tools ​

Rather than asking a language model to format LaTeX source, count words, or compute diffs by hand, TeXRA delegates those tasks to dedicated command-line utilities (latexindent, tex-fmt, latexdiff, texcount) and built-in extractors.

Settings → LaTeX → Dependencies: a detected tool shows a green check; a missing one shows a Not found tag and a Setup guide. On Settings → Plugins, a plugin that is ready reads Ready and one that is not reads Needs setup, with an Install in terminal or Open install page action where it has one.

Formatting tools ​

Supported formatters:

  • latexindent: the default formatter; highly configurable
  • tex-fmt: a faster alternative with simpler configuration

Formatting does not run on its own after agent execution. The selected formatter runs when you invoke it, and after Download arXiv Source unpacks a project. In the VS Code extension, run it from the Command Palette (Ctrl+Shift+P) → TeXRA: Format Current LaTeX File, which formats the file in the active editor.

Configuration: Formatter selection and installation live on the LaTeX tab () of the TeXRA Settings. Read the LaTeX configuration settings for the full set.

Version comparison with latexdiff ​

latexdiff produces a compiled PDF comparing two versions of a .tex document, with additions underlined in blue and deletions struck through in red. TeXRA shows one as the preview of a .tex edit awaiting your approval, and the assistant runs it in the shell when you ask for a diff against another file or a Git commit. Read the LaTeX Diff guide for both.

Document statistics with texcount ​

texcount reports word counts, heading counts, and math element counts so the model can reason about document scale and structure.

A program adds these statistics to its prompt when an agent starts it with args: { attachTeXCount: true }. Agents with bash can also run texcount themselves through the shell, for example texcount -inc main.tex.

attachTeXCount counts each input file on its own. In the VS Code extension, TeXRA: Count Words in Current TeX File counts the active file and asks how:

  • Count main file only: count the file on its own
  • Follow \input/\include and combine: follow \input{} / \include{} directives from the main file and combine the counts

Requirement

texcount must be on your PATH. It ships with most TeX distributions. Check Settings → LaTeX () → Dependencies: the TeXcount row shows a Not found tag when it is missing (texcount is not listed on the Plugins page). Install it with your TeX package manager.

Figure extraction ​

TeXRA extracts figures from your LaTeX so vision-capable models can see them.

Standard figures ​

An agent opens a figure file with read_file, which returns it as an attachment. Read the figures guide.

TikZ figures ​

TeXRA: Compile TikZ Figures from Current File wraps each tikzpicture of the open file in a standalone document and compiles it with pdflatex; in a chat, the assistant compiles a picture in the shell and reads the PDF. For a model without native PDF support, reading a PDF rasterizes it with Ghostscript plus GraphicsMagick or ImageMagick. The Plugins page does not list these; Settings → LaTeX → Dependencies shows a TeX Distribution row (pdflatex/latexmk) and an Image Processing row (Ghostscript + GraphicsMagick/ImageMagick), each with a setup guide when it is missing. texra doctor reports the compiler rows (latexmk, pdflatex) but not the image tools:

TikZ pipelineSettings → LaTeX
TeX Distributionpdflatex / latexmk: compiles each tikzpicture
Image ProcessingGhostscript + GraphicsMagick / ImageMagick: PDF to PNG
Not found Setup guide

TikZ extraction needs the compiler and, for rasterizing, Ghostscript with GraphicsMagick or ImageMagick. Here Image Processing is Not found; its Setup guide holds the install steps.

Read the TikZ figures guide for workflows and the installation guide for dependency setup.

Symbolic math with Wolfram ​

Agents run Wolfram Language code through wolframscript in the shell (wolframscript -code '...' or wolframscript -file) to verify calculations or perform symbolic algebra. It is not LaTeX-specific, but it is useful for validating mathematical content in papers and derivations.

The Wolfram row sits under Settings → Plugins (). Requires a local Wolfram Engine install.

For formatter paths, TikZ templates, and compile settings, read the configuration guide.
