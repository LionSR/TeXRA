# TeXRA Sample Project

This sample project pairs with the **Get started with TeXRA** walkthrough:

1. [Open the walkthrough](command:texra.openGettingStarted) if you closed it earlier.
2. Inspect `draft.tex` and decide which sections to improve.
3. [Open the TeXRA panel](command:texra.mainView.focus), pick a model, and type an instruction that names `draft.tex` (for example: _"Polish draft.tex: tighten the prose and preserve all math and citations."_).
4. Start the task and approve the `edit` program run the assistant proposes.
5. Review the revised document and diff in the **Tasks** view (or run [Compile TikZ figures](command:texra.compileTikzFigures) directly on a file with `tikzpicture` blocks).

See the [Quick Start guide](https://texra.ai/guide/quick-start) for details.
