# TeXRA Sample Project

This sample project pairs with the **Run your first TeXRA workflow** walkthrough:

1. [Open the walkthrough](command:texra.openGettingStarted) if you closed it earlier.
2. Inspect `draft.tex` and decide which sections to improve.
3. [Select your Input, Context, and Media files](command:texra.mainView.focus) in the **New task** view.
4. Pick an agent (such as `polish` or `correct`) and a model.
5. Enable auto-extraction to collect image paths and TikZ blocks before the run, or run [Compile TikZ figures](command:texra.compileTikzFigures) directly.
6. [Run the agent](command:texra.execute) and review the generated LaTeX diff.

See the [Quick Start guide](https://texra.ai/guide/quick-start) for details.
