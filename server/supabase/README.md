# TeXRA Supabase Edge Functions

This folder contains reference implementations for the Supabase services used by
TeXRA's authenticated proxy workflow.

## Functions

- `execute-remote-agent` – dispatches a remote agent execution. The function is
  responsible for decrypting agent prompts in-memory, forwarding the request to
  the TeXRA proxy, and streaming results back to the extension.
- `log-proxy-usage` – records usage and billing metadata generated by proxy
  sessions. Payloads are emitted by the VS Code extension whenever a proxy token
  is available.

Both functions ship with placeholders. Replace the `TODO` blocks with
project-specific logic before deploying. The extension expects the function
names to match the defaults defined in `texra.auth.remoteAgentFunction` and
`SUPABASE_USAGE_FUNCTION` (falling back to `execute-remote-agent` and
`log-proxy-usage`).
