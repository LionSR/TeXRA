# Welcome to TeXRA

TeXRA is your AI-powered LaTeX research assistant. It uses large language models to help you correct, polish, review, and restructure your academic papers — all within VS Code.

**What can TeXRA do?**

- **Correct** grammar, style, and LaTeX issues across your manuscript
- **Polish** your writing for clarity and academic tone
- **Draw** TikZ diagrams from descriptions or sketches
- **Review** papers with critical, reviewer-style feedback
- **Research** topics using AI-powered search and discussion
- **Orchestrate** multi-agent workflows that combine all of the above

## Getting started in 8 steps

Follow the checklist on the left to set up your first workflow. Each step links directly to the relevant command.

1. **Create the sample workspace** -- A bundled LaTeX project you can experiment with safely.
2. **Connect your API keys** -- You need an API key from Anthropic, OpenAI, Google, or another supported provider. Note: chat subscriptions (ChatGPT Plus, Claude Pro, etc.) do **not** include API access -- you need a separate developer API key.
3. **Stage your files** -- Tell TeXRA which files to read: your manuscript (Input), references, auxiliary files, and media.
4. **Pick an agent and model** -- Choose what TeXRA should do (correct, polish, draw, etc.) and which AI model to use.
5. **Enable automatic figure extraction** -- Let TeXRA find figures and TikZ blocks automatically before editing.
6. **Execute and follow progress** -- Start the agent and watch results stream into the Progress view.
7. **Review and diff outputs** -- Compare generated files against your originals using VS Code's built-in diff view.
8. **Pack and clean up** -- Archive outputs into a `History/` folder with Pack, or remove them with Clean.

> **Tip:** You can reopen this walkthrough anytime from the Command Palette: **TeXRA: Open Getting Started**.
