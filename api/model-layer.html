Model Layer (@texra-ai/llm) ​

@texra-ai/llm owns the model catalog (over llm-zoo), the provider catalog, route and endpoint decisions, OAuth subscription sign-in flows, and a single Model turn contract over three HTTP wire protocols (anthropic-messages, openai-responses, and google-interactions).

Scope and boundaries ​

  • Zero repo dependencies and zero ambient state. @texra-ai/llm imports nothing from @texra-ai/harness, reads no settings stores, calls no Effect.run*, and creates no AbortControllers outside Effect fiber interruption. Configuration arrives as values (RouteFacts, BindSpec), and credentials arrive through CredentialStore.
  • One turn in, one stream out. A Model prepares and streams a single turn (prepareTurn $\to$ streamTurn). Conversation state, tool execution, retry gates, durable permits, and persistence belong to @texra-ai/harness.
  • No internal retries. Vendor SDK retries are disabled. Every failure is classified into ModelError (kind, retryable, scope, retryAfterMs, quota, status) so the caller controls retry policy.
  • Explicit failure on unsupported input. Unsupported controls, media parts, or provider-hosted tool blocks fail in prepareTurn or stream decoding with ModelError rather than being silently dropped.

Running a turn (01-llm-turn.ts) ​

From packages/harness/example/01-llm-turn.ts:

ts
import { Effect } from 'effect';
import {
  completedTurn,
  decideModelRoute,
  OWN_KEY_ROUTE_FACTS,
  resolveRouteEndpoint,
  selectModel,
  turnCost,
} from '@texra-ai/llm';
import { bindModel } from '@texra-ai/llm/node';

const selected = selectModel('anthropic/claude-sonnet-5');
if (!selected) throw new Error('Unknown model.');

const route = decideModelRoute(selected.config, OWN_KEY_ROUTE_FACTS);
if (route.kind !== 'api-key') throw new Error(`Unexpected route ${route.kind}`);

const endpoint = resolveRouteEndpoint(selected.config, route, {
  endpoints: {},
});
if (!endpoint) throw new Error('No endpoint for the provider.');

const program = Effect.gen(function* () {
  // The provider's protocol, the route's config, credential scope and
  // billing, and every option default from the model and its route.
  const binding = yield* bindModel({
    model: selected.config,
    route,
    endpoint,
    credential: {
      kind: 'api-key',
      apiKey: process.env.ANTHROPIC_API_KEY ?? '',
    },
  });

  const turn = yield* binding.model.prepareTurn({
    system: 'Reply in one short sentence.',
    messages: [
      { role: 'user', content: [{ kind: 'text', text: 'State Theorem 1.' }] },
    ],
  });
  if (turn.mode !== 'foreground') {
    throw new Error('Expected a foreground turn.');
  }

  const result = yield* completedTurn(binding.model.streamTurn(turn));
  const cost = result.usage
    ? turnCost(binding.config, result.usage, { plan: false })
    : null;
  return { result, cost };
}).pipe(Effect.scoped);

Contract details ​

  • prepareTurn(request) -> ResolvedTurn: freezes the binding and validates request (messages, tool definitions, tool choice, reasoning controls, and media parts) before network I/O.
  • streamTurn(turn) -> Stream<TurnEvent, ModelError>: streams part deltas and a terminal completed event assembled by a single turn reducer across all protocols. Callers that want only the final TurnResult reduce the stream with completedTurn.
  • Optional members on Model:
    • uploadFile / releaseUploads: digest-keyed, model-scoped provider file upload cache, released when the binding's Scope closes.
    • background (submit, observe, cancel): remote execution for protocols that support detached turns (openai-responses, google-interactions). cancel claims cancellation only when the provider replies cancelled.

ModelError fields ​

Every failure from bindModel, prepareTurn, or streamTurn is a ModelError (_tag: 'ModelError'):

FieldMeaning
kind'invalid-request' · 'unsupported' · 'authentication' · 'rate-limited' · 'quota-exhausted' · 'context-overflow' · 'continuation-gone' · 'transport' · 'provider-rejection' · 'malformed-output' · 'observation-deadline'
retryableWhether repeating the request unchanged can succeed (derived from kind, status, and vendor reply metadata).
scope'model' (limit on this model) or 'route' (provider, credential, or endpoint).
retryAfterMsProvider-reported retry delay in milliseconds, when present.
quotaFor 'quota-exhausted': the exhausted plan (PlanRoute or null for account credit) and reset timestamp.
status, requestId, responseId, modelHTTP status and provider trace identifiers when a reply was received.

ModelErrorFields types these fields as plain data for persistence and IPC.
